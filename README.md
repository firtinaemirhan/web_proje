# Şamdan AI-MAP

Android Zararlı Yazılım Analiz Platformu (Android Malware Analysis Platform). 
Uygulama; VirusTotal, MobSF, ağ keşfi ve yapay zeka (Gemini/Ollama) entegrasyonu ile temel APK analizleri yapmanızı sağlar.

## Kullanım

```bash
# Bağımlılıkları yükleyin
pip install -r requirements.txt

# Uygulamayı çalıştırın
python app.py
```

Tarayıcınızdan `http://localhost:8080` adresine giderek uygulamaya erişebilirsiniz.
